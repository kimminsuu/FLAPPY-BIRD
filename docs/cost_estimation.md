## Supabase 프리 티어 주의사항

1. **7일 비활성 자동 정지**: 7일간 API 요청이 없으면 프로젝트가 일시정지됨
   - 대응: cron job으로 주기적 health check (GitHub Actions 활용 가능)
2. **백업 없음**: 프리 티어는 자동 백업 미제공
   - 대응: 주기적 pg_dump 또는 Pro 전환
3. **프로젝트 2개 제한**: 프리 티어는 최대 2개 프로젝트

## 비용 최적화 팁

1. **game_score 테이블 관리**: append-only 로그이므로 데이터가 빠르게 증가
   - 오래된 데이터 아카이빙 또는 집계 후 삭제 정책 필요
2. **이미지 CDN**: 새 이미지(~3.8MB)는 Vercel CDN에서 캐싱되므로 추가 비용 없음
3. **Static Export 유지**: SSR로 전환하지 않는 한 Vercel 비용 발생 가능성 낮음
4. **GitHub Actions**: 퍼블릭 레포 유지 시 CI/CD 무료
