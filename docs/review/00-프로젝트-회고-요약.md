## Top 5 교훈

### 1. "나중에 바꾸면 되지"는 비용이 크다
- localStorage → Supabase 전환에 6개 화면 + 2개 Context 수정
- **Day 1부터 최종 데이터 저장소를 사용할 것**

### 2. 파일 크기는 500줄이 한계
- game-page.tsx가 1,911줄까지 성장한 후에야 리팩토링
- AI 보조 개발에서 파일 크기 = 컨텍스트 비용
- **300줄 경고, 500줄 분리 필수**

### 3. 모바일 테스트는 일찍, 자주
- PC에서 60fps → Samsung S23에서 프레임 드롭
- Canvas save/restore, Array.splice, DPR 2.0이 주범
- **주 1회 이상 타겟 디바이스 테스트**

### 4. MEMORY.md의 빌드 명령어 기록이 최고 ROI
- 5단계 Android 빌드 체인을 한번 기록 → 20회+ 재사용
- **반복 명령어는 즉시 기록**

### 5. YAGNI (You Aren't Gonna Need It)
- Kakao 로그인, NextAuth, 랭킹 → 전부 삭제
- 수백 줄의 코드가 사전에 불필요하게 작성됨
- **"지금 필요한가?"를 먼저 물을 것**
